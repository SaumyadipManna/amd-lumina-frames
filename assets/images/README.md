# Image assets

The website currently loads illustrative architectural images from Unsplash using image URLs in `index.html` and `css/style.css`. The project gallery is explicitly identified as inspiration, not as a record of completed AMD Lumina Frames projects.

To use business-owned photographs, place optimized image files in this folder and update the relevant `src` attributes in `index.html` and the hero background URL in `css/style.css`. Keep useful alternative text on every content image. Use images you own or have permission to use.
