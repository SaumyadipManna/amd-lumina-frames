# Image assets

The supplied AMD Lumina Frames logo, product-specific SVG illustrations, sliding-window photo, and supplied door photos live in this folder. The gallery also includes the supplied black aluminium-framed sliding-door photo, as well as illustrations of uPVC casement doors and aluminium windows. The uPVC door gallery image is a local entryway composite made with the supplied door photo, which is currently shown with Toilet Fibre Doors. Product-card window and door illustrations automatically open once scrolled into view; reduced-motion preferences are respected.

To use business-owned photographs, place optimized image files in this folder and update the relevant `src` attributes in `index.html` and the hero background URL in `css/style.css`. Replace the logo with the original high-resolution artwork when available. Keep useful alternative text on every content image. Use images you own or have permission to use.
